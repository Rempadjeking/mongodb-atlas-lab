## 1. Цель работы
Создание бесплатного кластера в MongoDB Atlas, настройка удаленного доступа и выполнение базовых CRUD-операций (Create, Read, Update, Delete) для управления данными.

## 2. Пошаговое выполнение
### Шаг 1: Создание кластера и настройка доступа
- Развернут кластер **M0 Free Tier** (Cluster0).
- В разделе **Network Access** добавлен IP-адрес `0.0.0.0/0` (доступ разрешен).
- В разделе **Database Access** создан пользователь-администратор (Atlas Admin).

### Шаг 2: Работа с данными (CRUD)
Все операции выполнены через встроенный инструмент **Atlas Data Explorer**.
- **Create**: Создана база данных `labdb` и коллекция `users`. Документ успешно добавлен.
- **Read**: Выполнен поиск документа по фильтру `{ "name": "Mahammad" }`.
- **Update**: Изменен возраст в документе с помощью оператора `$set`.
- **Delete**: Протестирована функция удаления документа из коллекции.

## 4. Примеры команд (эквивалент mongosh)
```javascript
// Использование базы данных
use labdb

// Create (C)
db.users.insertOne({ name: "Mahammad", age: 19, specialty: "Data Analytics" })

// Read (R)
db.users.find({ name: "Mahammad" })

// Update (U)
db.users.updateOne({ name: "Mahammad" }, { $set: { age: 20 } })

// Delete (D)
db.users.deleteOne({ name: "Mahammad" })
